# dev-team

A local Claude Code plugin marketplace with one plugin, **devteam**: a multi-agent software team (orchestrator, architect, backend, frontend, data, devops, QA, devsecops, reviewers, debugger, tech writer, integrator) that uses Antigravity (Gemini) for cross-model review and overflow work.

```sh
claude plugin marketplace add ~/dev-team
claude plugin install devteam@devteam
```

See [plugins/devteam/README.md](plugins/devteam/README.md) for usage, configuration, adding roles and the debugging runbook.
